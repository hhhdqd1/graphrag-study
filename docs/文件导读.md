# 每个文件做什么

这里解释我们编写的源码、配置、测试，以及机器生成数据的作用。
注释用于帮助阅读，不代表需要把每个文件都运行一遍。

## 一、Python：真正运行后台的代码

| 文件 | 用途 | 谁调用它 | 是否单独运行 |
| --- | --- | --- | --- |
| `01_read_entities.py` | 读取实体与关系，打印样例，适合第一个练习 | 你 | 可以，只读索引 |
| `serve.py` | 启动网页服务，分发 API 请求，管理任务 | 你 | **日常启动入口** |
| `web_worker.py` | 执行一次 Local 或 Global 查询 | `serve.py` | 不必；命令行使用时必须传入参数 |
| `document_store.py` | 解析 PDF、内存预览、确认保存、原件来源管理 | `serve.py` | 不必；内部 `--extract` 由后台使用 |

### serve.py 的主要函数

- `settings` / `output_dir`：定位本项目配置和索引。
- `table` / `records`：读取 Parquet，并转换成网页可接收的数据。
- `model_health`：检查 Ollama 模型，而不是发起问答。
- `overview`：生成文档、实体、关系、社区报告及数量。
- `create_job` / `run_job`：把耗时工作放到后台，避免页面一直卡在请求上。
- `Handler.do_GET`：读取数据、网页和任务状态。
- `Handler.do_POST`：提交问题、预览/确认文档、启动索引、取消查询。
- `main`：真正启动本机 HTTP 服务；本项目默认端口为 8766。

### 网页与后台的接口

| 接口 | 做什么 | 是否改变知识库 |
| --- | --- | --- |
| `GET /api/overview` | 读取知识库概况 | 否 |
| `GET /api/health` | 检查模型 | 否 |
| `GET /api/documents/文件名` | 阅读文档及提取页码 | 否 |
| `GET /api/originals/文件名` | 下载已保存的 PDF 原件 | 否 |
| `POST /api/documents/preview` | 提取 PDF，生成内存预览 | 否，只建立有时限的内存记录 |
| `POST /api/documents/import` | 确认 PDF 入库 | 是，新增资料但不建索引 |
| `POST /api/documents/discard` | 取消 PDF 预览 | 否，清理内存预览 |
| `POST /api/documents` | 导入 UTF-8 TXT | 是，新增资料但不建索引 |
| `POST /api/index` | 构建/更新图谱和向量 | **是，会更新已有索引** |
| `POST /api/query` | 提交 Local / Global 问题 | 不改知识库，调用模型 |
| `GET /api/jobs/任务编号` | 读取进度或结果 | 否 |
| `POST /api/jobs/任务编号/cancel` | 停止查询 | 不改知识库；索引任务不在这里取消 |

### document_store.py 的关键区别

`preview_pdf` 只建立预览；`import_pdf` 才写入资料；GraphRAG 建索引是之后的独立操作。
解析在独立进程中运行，限制文件大小、页数、解码量和时间；它不会把 PDF 发送给云服务。
预览最多保留四份，15 分钟后失效；过期数据在下次 PDF 操作或服务结束时释放。
保存失败时，只回滚本次新建文件，不覆盖或删除原有资料。

## 二、web/：浏览器里的页面

| 文件 | 用途 | 如何生效 |
| --- | --- | --- |
| `index.html` | 定义导航、提问框、图谱、文档、报告和弹窗结构 | 浏览器加载首页 |
| `app.js` | 处理点击、请求 API、展示数据、轮询任务和 PDF 确认 | HTML 自动加载 |
| `styles.css` | 配色、字号、布局、手机适配和交互反馈 | HTML 自动加载 |
| `favicon.svg` | 浏览器标签上的图标，不是模型或业务代码 | HTML 引用 |

不要直接双击 HTML 来替代后台启动；页面需要同一个 HTTP 服务下的 `/api/` 接口。

## 三、根目录配置和说明

| 文件 | 用途 | 注意 |
| --- | --- | --- |
| `settings.yaml` | 模型、输入、切块、向量库、索引和检索设置 | 中文注释对应各阶段；先不要随意改模型名 |
| `.env` | 本机运行变量 | 当前连接 Ollama；真实密钥不要提交 Git |
| `.env.example` | 环境变量样例 | 换电脑时用作模板 |
| `.python-version` | 固定 Python 3.11.16 | 给环境工具读取，不能插入解释性注释 |
| `requirements.txt` | 核心依赖 | GraphRAG、pypdf 等已验证版本 |
| `requirements-lock.txt` | 全部间接依赖版本快照 | 完整复现优先用它 |
| `.gitignore` | 指定哪些文件不提交 Git | 不是删除规则，不影响本机读取 |
| `README.md` | 启动入口、学习顺序与常见问题 | 第一次先读这里 |
| `网页使用说明.md` | 网页完整操作说明 | 不等于后端代码 |
| `docs/文件导读.md` | 当前文档 | 查每个文件的职责 |

## 四、提示词：不是 Python 脚本

`prompts/` 的 13 个 TXT 是 GraphRAG 的模板。用途逐项列在 `prompts/README.md`。
它们会进入模型提示，因此没有向原模板插入教学注释；修改其中内容可能改变索引或回答。

## 五、资料和机器生成数据

- `input/README.md`：说明原始输入和 PDF 派生 TXT 的区别。
- `input/technology_companies_zh.txt`：学习用科技公司原文，保持原内容。
- `output/README.md`：解释六张 Parquet 表和 LanceDB。
- `output/documents.parquet`：文档级记录。
- `output/text_units.parquet`：切分后的文本块。
- `output/entities.parquet`：实体节点。
- `output/relationships.parquet`：节点之间的关系。
- `output/communities.parquet`：社区分组及层级。
- `output/community_reports.parquet`：社区报告。
- `output/stats.json`：索引统计，不是启动配置。
- `output/lancedb/`：三类向量表及其数据、版本、事务文件；不能作为普通文字编辑。
- `source_documents/`：确认导入后自动生成，保存 PDF 原件和来源元数据。
- `cache/`、`logs/`：运行后自动生成，分别用于缓存和排错。

二进制表、向量库、原始资料以及自动生成的元数据不插入注释，避免损坏数据或改变原文。

## 六、tests/：检查功能是否正确

| 文件 | 用途 | 是否需要先启动网页 |
| --- | --- | --- |
| `test_pdf_import.py` | 13 项 PDF 后台回归，含真实 GraphRAG 文本加载 | 不需要，自动使用临时服务 |
| `pdf_fixture_server.py` | 给浏览器 PDF 测试提供临时知识库与样例 | 不需要手动运行 |
| `web_pdf.mjs` | 浏览器完整 PDF 导入流程 | 不需要，自动创建临时服务 |
| `web_ui.mjs` | 引用正确性、四路由和三尺寸布局 | 需要，默认 8766 |
| `web_smoke.mjs` | 实际 Local/Global 问答及来源验收 | 需要，也需要 Ollama |

`.mjs` 测试使用本机 Node 与 Chrome。测试文件中注明的外部浏览器工具路径只服务验收，
不属于应用运行依赖；换电脑时需要调整该路径，日常启动 Python 后台不受影响。

## 七、PyCharm 配置

- `.idea/.name`：IDE 中显示的项目名，机器读取，不加解释文字。
- `.idea/misc.xml`：Python 解释器名称和项目设置。
- `.idea/modules.xml`：告诉 IDE 载入哪个项目模块。
- `.idea/graphrag-study.iml`：源码与测试目录，排除环境、索引和运行产物。
- `.run/01_查看实体和关系.run.xml`：只读练习的运行配置。
- `.run/02_启动知识工作台.run.xml`：服务入口的运行配置。
- `.run/03_验证PDF后台.run.xml`：完整 PDF 后台测试的运行配置。
- `.idea/workspace.xml`：打开项目后由 PyCharm 自动维护窗口和临时状态，不作为教学源码。
- `.venv/`：第三方库和解释器入口，不逐文件标注，不在这里写自己的代码。
